# Quill by LuckiusDev

---

Quill is a tool made for Unity `6000.6.0f1` and onwards, using `Graph Toolkit`, to create flexible and complex dialogues for your game.
Customize your UI any way you want, and use the composition 'plug-and-play' of Quill to create dialogues with branching path, logic and more!

## Features
- Graph-based tool using Unity `Graph Toolkit`.
- Event system and modules to interface your UI with the running dialogue session.
- A bunch of nodes ready to use out of the box : `Dialogue`, Branches, `Condition`, `Wait For Input`, `Variables`,...

## How to Start

1. Create a `QuillActorData` scriptable object by going to `Assets > Create > LuckiusDev > Quill > New Actor Data`,
2. Create your first dialogue by going to `Assets > Create > LuckiusDev > Quill > New Dialogue Graph`,
3. Open your dialogue graph and add a `Start` node as well as any other node you want,
4. Look at the `Scene_QuillSample` scene to setup and wire everything (you need a to add `Dialogue Director` and modules).

You should be good to go!
